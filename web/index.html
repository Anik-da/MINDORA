The Tested Workflow

MINDORA is validated against the LibreOffice Calc bar chart workflow. The coach verifies every action through screen vision and local OCR candidate grounding.

Web Companion

Accessible In-Browser Guidance

Upload screenshots from any OS or browser. The web interface extracts text candidates, reasons with Gemini multimodal vision, and draws high-contrast grounded bounding boxes directly over your screenshot.

  • Instant preview without installing desktop agents
  • Turn-by-turn verification with fresh screenshots
  • Grounded OCR candidates: zero hallucinated coordinates
Windows Desktop App

Live Desktop Transparent Overlay

The native Electron companion runs locally on Windows 11. It automatically hides its own UI during screen capture and projects transparent click-through highlights directly onto your live LibreOffice Calc window.

  • One-key check via shortcut (Ctrl+Alt+U)
  • Transparent overlay with pass-through click interaction
  • Tested foreground window scoping & 125% DPI mapping
