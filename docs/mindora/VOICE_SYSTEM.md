# Voice System

Voice interactions are optional and off by default. Speech recognition uses Electron's packaged Chromium `SpeechRecognition`/`webkitSpeechRecognition` implementation; speech synthesis uses Chromium `speechSynthesis` and installed system voices. The pet microphone action starts one-shot recognition. The compact pet panel also offers explicitly activated continuous conversation, push-to-talk behavior, interim transcript display, and an immediate stop button. Recognized utterances are submitted to the real Gemini-planned agent workflow. Completed task responses and failures update the pet panel; completed responses are spoken when continuous conversation is active. A separate multi-turn Gemini chat thread is not currently implemented.

Microphone permission is requested after a user activates the voice control or continuous mode. Electron's permission handler allows an audio-only media request from the companion window while a short permission request is armed and voice remains enabled. Other renderer origins and media permission requests are denied. Listening stops when the user presses Stop, releases push-to-talk, disables voice, or quits the app. Recognition results are displayed in the task bubble and chat surface.

The app does not record or persist raw audio. Chromium speech recognition can require internet and may use an OS/Chromium service; offline recognition is not guaranteed and no separate paid speech API is configured. Gemini task planning requires a valid Gemini key and network access. System TTS voices are generally local, depending on Windows voice availability. No additional per-minute voice provider charge is introduced; Gemini usage follows the user's existing account pricing.

If speech recognition is unavailable, permission is denied, no speech is detected, or Gemini configuration/network fails, the companion shows an error and leaves text/chat available. Push-to-talk is exposed on the microphone control; hold it while speaking when enabled. Optional continuous mode returns to listening after assistant speech finishes and does not listen while MINDORA is speaking. Multi-turn Gemini memory, microphone device selection, and packaged Windows speech-provider reliability still need product QA.
